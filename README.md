# Margo — сайты на заказ

Одностраничный сайт услуги «Создание сайтов на заказ»: лендинги, корпоративные сайты,
интернет-магазины, поддержка.

## Особенности

- Статический сайт: HTML + CSS + ванильный JS, без сборки и зависимостей
- Стиль вдохновлён aave.com: светлая тёплая тема, мягкий фиолетовый акцент, скруглённые карточки
- Переключатель тёмной темы (кнопка ◐ в шапке и в футере; выбор запоминается в браузере;
  тёмную тему можно открыть сразу ссылкой `?theme=dark`)
- Адаптивная вёрстка (мобильные устройства от 375 px)

## Запуск локально

```bash
npm run dev        # node server.js — сервер на http://127.0.0.1:7100/
```

Порт и хост можно переопределить: `node server.js --port 8080 --host 0.0.0.0`.

## Настройка контактов

Реальные email и телеграм задаются в `src/main.js`, константа `CONTACTS`.
Пока они пустые, в блоке «Контакты» показывается заглушка.

## Структура

```
index.html   — разметка и все стили
src/main.js  — год в футере, переключение темы, блок контактов
server.js    — минимальный статический сервер для локального превью
```
